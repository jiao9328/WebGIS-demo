◆ 链路 1 · 启动链路（引擎随地图就绪统一 boot）
① 入口main.js → App.vue 建 mapboxgl.Map + L7 Scene（同画布）
→
② bootstyle 加载后：initControl → initLayer → initBusLayers（注册全部图层条目）→ initRouteClassLayers
→
③ 引擎vehicleSim.start()：种子生成时刻表 → 首班车布上线 → 挂 1s ticker
→
④ 挂载sceneMap 赋值 → UI 注入生效 · 首页飞线网总览
→
⑤ 收尾天气预取 + 「智慧公交系统已就绪，当前 N 辆车在线」播报
◆ 链路 2 · 车辆仿真数据链路（系统心跳，1s 循环）
① tick每 1s 推进每辆车：站间里程 += 速度 ×（路况系数 × 事件系数）
→
② 状态机运行 ↔ 停站（驻留 15~40s）→ 首末站折返 / 回场；满载率随乘降函数
→
③ 快照写 store.busVehicles + 站台 arrivals（ETA 按当前速度外推）+ 异常 opsAlerts
→
④ 渲染vehicles 层 setData（4Hz 节流）· 实时栏 / 图表随 store 响应式刷新
→
⑤ 告警晚点 / 故障 / 拥挤入列 → speech 播报 + 调度页红点
◆ 链路 3 · AI 指令链路（「问车 / 叫车」全流程）
① 提问「35 路还有几分钟到淄博站？」
→
② 解析DeepSeek query_arrival 工具调用，或离线规则命中「线路 + 站 + 时间词」
→
③ 查询aiExec 读 store.arrivals：定位下一辆 35 路、按站距与 ETA 计算分钟数
→
④ 应答中文回复 + 站台卡展示各方向倒计时 + 语音播报
→
⑤ 追问「那辆车现在在哪」→ track_vehicle 地图聚焦 + 尾迹（多轮工具链）
◆ 链路 4 · 登录认证链路（M0 · 大屏的门禁）
① 访问未登录打开任意地址 → 路由守卫校验失败 → 重定向 /login
→
② 提交账号 + 密码 → POST /api/auth/login（Vite 同源代理 → auth-server:3001）
→
③ 校验查 MySQL users → bcrypt.compare 比对哈希（10 轮加盐）
→
④ 放行成功 → 签发 JWT 存前端 → 进入大屏；Header 显示当前用户
→
⑤ 失守密码错误中文提示 / 限速拦截 · 过期 401 → 清 token 回登录页 · 退出调 /logout
